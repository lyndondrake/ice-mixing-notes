Lemma 21 (a state repeated periodically)

Repeating a state onto a larger cell keeps it frozen and odd, so Theorem H passes from a cell to its divisors.

A frozen state of the cell \((a, b, c)\), repeated periodically, is a frozen state of the cell \((k_1 a, k_2 b, k_3 c)\) for any positive integers \(k_1, k_2, k_3\); it has an odd hexagon exactly when the original has, and the same set of moments. So Theorem H on the larger cell implies Theorem H on the smaller.
